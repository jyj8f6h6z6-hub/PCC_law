# 工程會電子法規彙編 v6.2

本版修正：
- 修復 v6 因法規引用辨識運算過重造成頁籤看似無法點擊的問題。
- 函釋中的法規引用改為一次掃描145筆法規名稱。
- 支援「機關委託資訊服務廠商評選及計費辦法」第12條等「法規名稱＋條號」正確連結。
- 支援政府採購法、施行細則、同法、同辦法、本法、本辦法及近接條號的上下文繼承。
- 桌面版開啟法條時採左右並排，不覆蓋左側函釋；關閉後恢復全寬。

請用 VS Code Live Server 或 GitHub Pages 開啟 index.html。


## v6.3 修正
- 修正 v6.2 啟動時一次計算所有逐條函釋數量造成頁面卡住。
- 函釋關聯索引改為背景分批建立，頁籤可立即操作。
- 採購法逐條的函釋數量先顯示「計算中…」，背景索引完成後自動更新。
- 保留函釋正文法規條文超連結及左右並排法條面板。


## v6.6
- 從PRMS原始HTML重新解析3,666筆「根據」欄位。
- 採購法逐條分為「PRMS原始法規依據－精準關聯」與「函釋全文提及－延伸關聯」。


## v6.6
- 修正「本辦法／同辦法／該辦法／前開辦法／本法／同法／該法」的上下文追溯。
- 會先找前文正式法規名稱，再找可唯一對應的法規簡稱；無法確定時不建立連結。
- 例如「各機關利用共同供應契約辦理採購，如依本辦法第9條」會連到《共同供應契約實施辦法》第9條。


## v6.6 修正
- 修正「採購法第46條及其施行細則第50條」等母法轉施行細則的引用判斷。
- 支援「及其施行細則／暨施行細則／與其施行細則／本法施行細則／該法施行細則」等關係詞。
- 若無法明確找到前一母法對應的施行細則，則不建立連結，避免誤判。

## v6.7 更新
- 新增「法規智慧換行」：自動清除工程會舊版電腦網頁固定欄寬造成的句中換行。
- 例如「規\n定」會顯示為「規定」、「功能，\n確保」會顯示為「功能，確保」。
- 真正的段落、項、款、目及「一、二、三、」「1. 2. 3.」等清單換行仍保留。
- 此功能只在網站載入時整理顯示文字，不會修改 `data/laws.json` 原始資料，方便日後與工程會來源核對。
