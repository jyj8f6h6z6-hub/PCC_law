# 工程會電子法規彙編（離線 / PWA 版）

政府採購法、施行細則、工程會 10 類主管法規 145 筆、工程會 PRMS 函釋 3,666 筆的查詢網站。
純前端靜態網站，部署於 GitHub Pages，可安裝到手機主畫面並離線使用。

網址：https://jyj8f6h6z6-hub.github.io/PCC_law/

## 檔案結構

| 路徑 | 用途 |
|---|---|
| `index.html` | 頁面骨架 |
| `app.js` | 搜尋、閱讀、函釋對照等所有功能 |
| `style.css` | 樣式 |
| `sw.js` | Service Worker（離線快取） |
| `manifest.webmanifest`、`icon.svg` | PWA 安裝資訊與圖示 |
| `offline.html` | 首次未完成快取時的離線提示頁 |
| `data/laws.json` | 工程會主管法規（由更新程式產生，含已廢止法規及狀態） |
| `data/letters.json` | 3,666 筆 PRMS 函釋（原始資料，不修改） |
| `data/act_rules_map.json` | 本法與施行細則對照表（人工確認版） |
| `json/procurement_act.json` | 政府採購法逐條 |
| `json/procurement_rules.json` | 政府採購法施行細則逐條 |

## 程式碼慣例

- **條號換算只寫在 `app.js` 開頭一處**：
  - `articleKey('第5條之1')` → `'5-1'`：內部比對、索引、對照表都用這個值。
  - `displayArticleNo('第5-1條')` → `'第5條之1'`：資料中的原始條號轉成畫面顯示。
  - `articleLabel('5-1')` → `'第5條之1'`：內部值轉成畫面顯示。
  - 需要換算條號時一律呼叫這三個函式，不要另外寫 `replace(...)`。
- **資料筆數不要寫死**：`index.html` 裡用 `<span data-stat="laws">145</span>`（`laws`／`letters`／`cats`）標記，
  資料載入後 `fillStats()` 會自動換成實際筆數；`app.js` 中請用 `STATS.laws` 等變數。
- **排版**：用 VS Code 的「格式化文件」（Windows：Shift+Alt+F；Mac：Shift+Option+F）。
  若安裝 Prettier 擴充套件，建議設定：單引號、每行 110 字。

**不要放進這個資料夾的東西**：備份用的 zip、下載器、尚未啟用的資料檔。
GitHub Pages 上的每個檔案都可以被任何人直接下載。

## 更新法規資料

法規資料由 `update_laws.py`（放在 `D:\@@網站製作\工程會資料更新\`，**不在**本資料夾）下載工程會網站後產生，
會自動改寫 `data/laws.json`、`json/procurement_act.json`、`json/procurement_rules.json`，並更新 `sw.js` 的快取版本。
不要手動編輯這三個檔案，下次更新時會被覆蓋。詳見更新程式資料夾內的「使用說明.md」。

## 更新版本時的檢查清單

1. 修改 `sw.js` 第一行的 `CACHE` 版本字串，否則已安裝的手機會一直使用舊檔。
2. 若新增、改名或刪除 `app.js` 會讀取的資料檔，同步修改 `sw.js` 的 `CORE` 清單。
   清單中只要有一個檔案不存在，離線功能就會整個失效。
3. 在下方「版本紀錄」新增一段。
4. commit 訊息寫上版本與重點，例如：`v6.17.5 修正離線快取清單`。

## 離線使用

首次透過 HTTPS（GitHub Pages）或 localhost（VS Code Live Server）成功開啟後，瀏覽器會快取網站介面與全部法規、函釋資料。
之後即使沒有網路，法規閱讀、函釋閱讀及全文搜尋仍可使用。工程會、PRMS 等外部連結在離線時無法開啟。

直接雙擊 `index.html`（file:// 模式）不支援 Service Worker，也無法載入資料，請改用 Live Server。

### 手機安裝

1. 先在有網路時完整開啟網站一次，等待資料載入完成。
2. iPhone Safari：分享 → 加入主畫面。
3. Android Chrome：選單 → 安裝應用程式 / 加到主畫面。
4. 安裝後開啟一次，再切飛航模式測試。
